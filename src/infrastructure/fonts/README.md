# Portfolio typography

- **Cabinet Grotesk**: display headings and large editorial links.
- **Switzer**: reading text, navigation, forms and captions.

Original, unmodified variable WOFF2 files from Indian Type Foundry's
[Fontshare](https://www.fontshare.com/). Sources:
[Cabinet Grotesk](https://www.fontshare.com/fonts/cabinet-grotesk) and
[Switzer](https://www.fontshare.com/fonts/switzer).

Both use the [ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl),
version 2.0 (17 August 2026). Its grant permits commercial website use and
self-hosting. The font files must remain unmodified; do not subset or convert
them. A third party wishing to use the fonts for a separate project should
obtain their own copies from Fontshare.

Downloaded on 30 October 2026 from the official Fontshare API's WOFF2 sources.
`next/font/local` serves both files with the application, with no runtime
dependency on a font CDN.
